Project 1170
Personal OS

A bespoke, zero-distraction personal operating system anchored by a strict 1095-day countdown — roughly 3 years — to a singular high-stakes personal deadline. Custom-built across Desktop, Web, and Android with a brutalist UI philosophy: no colours, no comfort, only accountability.

Desktop App Web Android Brutalist UI Countdown Logic Goal Tracking Python / JS / Kotlin

The Philosophy

Productivity systems fail because they are designed to be comfortable. Todo apps have friendly colours, motivational quotes, and satisfying animations. They gamify the experience — which is precisely why they don't work for high-stakes, multi-year goals.

Project 1170 is built on a single, brutal truth: every day that passes is a day permanently subtracted. The interface does not celebrate you. It does not give you points. It counts down, relentlessly, in monochrome.

Architecture: Three Platforms, One Data Core

  • Desktop (Python/PyQt6): The primary environment. A full-screen lock-mode application that launches at system startup, blocking distraction before the workspace is unlocked.
  • Web (Vanilla JS): A zero-dependency, statically hosted dashboard for cross-device access. No frameworks — brutally minimal load time.
  • Android (Kotlin): Home screen widget displaying only the day count and current primary objective. No app — just a widget. Maximum presence, minimum friction.

Data Persistence & Sync

All goal data is stored in a local SQLite database on the desktop, with a nightly export to a flat JSON file synced via a private GitHub repository. The web and Android versions pull from this JSON endpoint, ensuring all platforms reflect the same state without a cloud dependency or subscription service.

The system enforces a daily audit: before the desktop lock-screen can be dismissed, you must log what you completed the previous day. There is no skip button. This creates an unbroken daily accountability record that doubles as a performance journal.
