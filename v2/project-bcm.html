PRJ_03 Automotive Embedded

Custom Automotive
Body Control Module

A fully configurable, dual-processor gateway designed to manage vehicle electrical systems. Features real-time RTOS scheduling, persistent FRAM memory, and wireless CAN bus telemetry via WebSocket integration.

The Hardware Architecture

A client required a universal Body Control Module (BCM) that could be adapted to disparate vehicle setups (handling lights, wipers, and dashboard signals) without ever needing to modify the core firmware logic.

I engineered a dual-core architecture. The STM32F4 handles all mission-critical real-time I/O and acts as the primary CAN bus gateway. Alongside it, an ESP32 co-processor manages the wireless stack, communicating with the STM32 over a high-speed UART bridge.

Persistent Modular State

To make the system universal, every configuration parameter—voltage thresholds, pin mappings, and I/O behavior logic—is stored in an onboard FRAM (Ferroelectric RAM) chip. Unlike EEPROM, FRAM allows for virtually infinite write cycles without wear.

If power is cut during operation, the exact vehicle state is instantly recovered upon reboot. Furthermore, every memory read passes through a strict CRC-16 validation check. If data corruption is detected, the STM32 defaults to a hard-coded safe state, preventing catastrophic electrical actuation.

Live Telemetry & OTA

The ESP32 is not just a Bluetooth receiver; it hosts a lightweight asynchronous web server. When a technician connects to the module's local Wi-Fi, they can open a WebSocket-based Dashboard in any browser to monitor live CAN bus traffic and physical I/O states in real-time—no proprietary diagnostic tools required.

Configuration files can be pushed over Bluetooth or USB, and core firmware updates to the ESP32 are handled via Over-The-Air (OTA) flashing, allowing field updates without pulling the unit out from under the dashboard.
