PRJ_02 Control Systems

Self-Balancing
Dual-Arm Beam

An advanced mechatronic control system designed to stabilize a highly dynamic, non-linear physical structure using high-torque BLDC motors, FOC commutation, and 6-DoF sensor fusion.

The Control Problem

Balancing a dual-arm beam is an inverted pendulum problem scaled up. The system is inherently unstable; any deviation from the horizontal plane accelerates gravity's pull, requiring immediate, calculated counter-thrust.

I architected the solution around a Texas Instruments TM4C123G microcontroller running bare-metal C. Instead of basic brushed DC motors, the system utilizes Brushless DC (BLDC) motors driven by Field Oriented Control (FOC) for instantaneous torque delivery without the latency of mechanical brushes.

State-Space & PID Cascade

A simple PID loop is insufficient for the complex dynamics of dual rotors. The architecture employs a Cascaded Control Loop:

1. The Outer Loop monitors the MPU6050 (filtered via Madgwick) to calculate the angular error from the 0° setpoint.

2. The Inner Loop takes the output of the outer loop as a rate-of-change target, driving the high-speed SVPWM signals to the motor drivers.

This was mathematically modeled in MATLAB prior to hardware deployment using State-Space representation (ẋ = Ax + Bu) to prove Lyapunov stability.

Hardware Fault Protection

Control theory fails when hardware burns. I integrated ACS712 Hall-Effect current sensors directly inline with the BLDC phases. The TM4C's internal ADC samples these lines at 1M/s. If the beam strikes an object or a rotor stalls, the current spikes instantly. The bare-metal firmware triggers a high-priority Hardware Fault Interrupt, killing the PWM signals within 12 microseconds, saving the MOSFETs from thermal runaway and preventing physical destruction.
