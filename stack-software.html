MATLAB & Simulink

Control Systems Simulation
02

Before deploying C-code to physical microcontrollers, I mathematically prove system stability using MATLAB and Simulink. I build State-Space models and transfer functions that mirror the physical dynamics of DC motors and robotic linkages.

I specialize in PID tuning via root locus analysis and Bode plots. By simulating step responses with varying disturbance injections, I can perfectly tune a system's settling time, overshoot, and steady-state error digitally.

This "Model-Based Design" approach ensures that when the code is finally flashed to the hardware, the robotic arms balance perfectly on the first attempt without destructive oscillations.

Data Pipelines & ETL

Data Structuring & Cleaning
04

Raw data is useless without structure. I build ETL (Extract, Transform, Load) pipelines to handle chaotic datasets gathered from scraping or hardware telemetry.

Using Pandas and NumPy, I process arrays of data, applying vectorization rather than slow iterative loops. This allows for the rapid cleaning of datasets: handling missing null values, normalizing erratic sensor floats, and reshaping data matrices.

The resulting pristine data is then serialized into structured JSON, CSV, or injected into SQL databases, ready for downstream algorithmic consumption or UI rendering.

Distinctive UI/UX

Brutalist & Anti-Cookie-Cutter Design
05

I reject generic, AI-generated aesthetics, overused fonts (like Inter or Roboto), and predictable white-and-purple SaaS templates. A portfolio or application should have a distinct, unapologetic character.

I practice Digital Brutalism and Structural Design. This involves strict grid systems, high-contrast typography (pairing expressive serifs like Fraunces with technical mono-fonts), and the deliberate use of negative space.

Every element is customized through CSS variables (Design Tokens). From custom SVG noise overlays to mathematical clamp() functions for fluid typography, I ensure the UI adapts perfectly across viewports without ever losing its intended atmospheric edge.
